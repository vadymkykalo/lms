# Вступ до Backend-розробки

Ласкаво просимо на перший урок! У цьому курсі ви навчитеся основам і просунутим аспектам backend-розробки з використанням **Spring Boot**.

---

## Що таке Backend?

Backend — це серверна частина додатка, яка обробляє запити від клієнта (наприклад, від веб-додатка) та повертає дані або виконує необхідні дії.

---

## Основні теми курсу

- **Основи REST API** — створення інтерфейсів для взаємодії з клієнтами.
- **Аутентифікація та авторизація** — захист додатків за допомогою JWT.
- **Робота з базами даних** — використання PostgreSQL і Redis для збереження даних.
- **Інтеграції** — підключення до зовнішніх сервісів.
- **Kafka та мікросервіси** — основи роботи з чергами та розподіленими системами.

---

## Як виглядає backend?

Нижче наведено приклад простого контролера на Java з використанням Spring Boot:

```java
@RestController
public class HelloController {

    @GetMapping("/hello")
    public String sayHello() {
        return "Привіт, світ!";
    }
}
